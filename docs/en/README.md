# Documentation and manufacturer guides

This index links to Yamaha's official manual and project-authored guides. The full manufacturer's manual and Bluetooth adapter guide are not embedded in Yamahama or copied to `installfiles`. Firmware, touch-panel and reset guides are also available in the application's help.

- [Yamaha SR-C30A — full manufacturer's User Guide (English PDF, Yamaha website)](https://download.yamaha.com/files/tcm:39-1545200): the reviewed guide has 96 pages; touch-panel locking (Child Lock) is on page 54. This link does not require a local PDF copy.
- [Disabling and switching Bluetooth adapters in Windows](adaptery-bluetooth.txt): identifying ASUS/MediaTek, disabling a radio, switching adapters and troubleshooting code 31. This is a separate guide, not an application feature.
- [Polish documentation index](../README.md).

## Optional local copy

A separately downloaded file may be kept locally as `docs/Yamaha-SR-C30A-User-Guide-EN.pdf`, relative to the project root. This is optional reference material and is not intended for inclusion in the public repository or application package. Cloning the repository will not supply that PDF — use the Yamaha links above. It is not required to build or run the application.
