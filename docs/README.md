# Dokumentacja i instrukcje producenta

Ten indeks prowadzi do oficjalnej instrukcji Yamaha oraz poradników projektu. Pełna instrukcja producenta i poradnik adapterów Bluetooth nie są osadzane w Yamahamie ani kopiowane do `installfiles`. Poradniki firmware, panelu dotykowego i resetu są dostępne także w pomocy programu.

- [Yamaha SR-C30A — pełna instrukcja producenta (PDF, angielski, serwis Yamaha)](https://download.yamaha.com/files/tcm:39-1545200): sprawdzona instrukcja ma 96 stron; blokada panelu dotykowego (Child Lock) jest na stronie 54. Odnośnik nie wymaga lokalnej kopii PDF.
- [Wyłączanie i przełączanie adapterów Bluetooth w Windows](adaptery-bluetooth.txt): polska instrukcja identyfikacji ASUS/MediaTek, wyłączania radia, przełączania adapterów i postępowania przy kodzie 31. To osobny poradnik, nie funkcja programu.
- [English documentation index](en/README.md).

Dane tej kopii: tytuł „SR-C30A User Guide”, 2 543 705 bajtów oraz SHA-256 `a0a77f8c805842191427da7955e4cdea82b1b085cdccd7b5bca77816f158d19a`. To identyfikacja sprawdzonego pliku, nie gwarancja niezmienności przyszłych pobrań.

## Opcjonalna kopia lokalna

Osobno pobrany plik może być przechowywany lokalnie jako `docs/Yamaha-SR-C30A-User-Guide-EN.pdf`. Taka kopia jest opcjonalnym materiałem do odczytu i nie jest przewidziana do dołączenia do publicznego repozytorium ani pakietu programu. Pobranie repozytorium nie dostarczy tego PDF — korzystaj z odnośników Yamaha powyżej. Nie jest on potrzebny do kompilacji ani działania aplikacji.

Publiczna dostępność instrukcji i wskazanie jej autora nie oznaczają zgody na redystrybucję. Projektowe poradniki nie zastępują instrukcji bezpieczeństwa Yamaha i nie są autoryzowanym tłumaczeniem pełnego podręcznika. Autorskie poradniki projektu są dostępne na GPL-3.0-only, zgodnie z [README](../README.md) i [LICENSE](../LICENSE). Instrukcja Yamaha zachowuje własne warunki.

## Pozostałe poradniki soundbara

[Firmware](firmware-sr-c30a.txt), [Child Lock](panel-dotykowy.txt) oraz [reset](reset-sr-c30a.txt) opisują funkcje i ograniczenia soundbara. Firmware otworzysz offline przez **Pomoc → Firmware**, a poradniki panelu i resetu przez **Pomoc → Pomoc i informacje o aplikacji…**. Osobna dystrybucja instrukcji producenta i poradnika adapterów nie wyłącza sterowania soundbarem przez Bluetooth ani pomocy osadzonej w programie.
